# 피클 하우스 · 우리 집 집안일

종화와 수뚜가 함께 쓰는 집안일 체크리스트입니다. 크림·우드 톤의 평면도에서 방을 누르면 그 방의
집안일이 열리고, 파란 `ㅂ`(종화 피클)과 분홍 `ㅂ`(수뚜 피클)이 방을 오가며 응원합니다.

- 배포 주소: <https://mpx9109-alt.github.io/Pickle-house/>
- 정적 페이지 한 장: `index.html` + `assets/style.css` + `assets/app.js` (프레임워크·빌드 없음)
- CSS/JS를 고치면 `index.html`의 `?v=` 숫자를 올려 주세요 (브라우저 캐시 때문)
- 외부 요청 없음 (폰트·아이콘·이미지 모두 로컬/시스템)

## 방 구성

| 방 | 집안일 |
| --- | --- |
| 🛋️ 거실 | 로봇청소기·청소기, 물걸레질, 소파·장난감 정리, 환기 |
| 🍳 주방 | 설거지·식세기, 음식물쓰레기, 정수기 주변, 장보기 목록 |
| 🛁 욕실 | 샤워기·세면대 필터, 배수구 머리카락, 수건 교체, 곰팡이·물때 |
| 🛏️ 안방 · 아이방 | 빨래·건조기, 침구 털기, 아이 용품·기저귀/젖병 |
| 🚪 현관 · 다용도실 | 분리수거, 택배 박스 정리, 신발장·현관 쓸기 |

## 기능

- **방 카드**: 방마다 오늘 완료 개수와 진행 막대 표시. 누르면 그 방의 체크리스트가 열립니다.
- **체크리스트**: 체크/해제, 담당 배지(`종화`·`수뚜`·`같이`)를 눌러 담당 전환, 주기(`매일`·`주간`·`수시`) 표시, 삭제.
- **추가**: 전체 목록 아래 폼(방·담당·주기 선택) 또는 방 상세 안에서 바로 추가.
- **오늘 달성률**: 상단에 전체 퍼센트와 진행 막대, 담당자별 완료 수. 필터(전체·종화·수뚜·같이)로 목록을 좁힐 수 있습니다.
- **피클 응원**: 방을 열면 두 피클이 그 방으로 뛰어가 응원 말풍선을 띄우고, 가만히 두면 이따금 다른 방으로 옮겨 갑니다.
- **낮/밤 램프**: 크림 톤 낮과 따뜻한 밤을 오갑니다.
- 저장은 브라우저 `localStorage`에만. 날짜가 바뀌면 체크가 초기화됩니다.
- 모바일·PC 대응, `prefers-reduced-motion` 존중, 키보드 포커스·Esc 닫기 지원.
