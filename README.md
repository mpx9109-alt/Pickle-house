# 피클 하우스 · 아늑한 일반 집

박종화 님의 집을 닮은 1페이지 미니 비서실입니다. 크림·우드 톤의 평면도에서 방을 누르면
그 방의 지금 챙길 일이 열리고, 파란 `ㅂ` 모양 피클이 그 방으로 따라갑니다.

- 배포 주소: <https://mpx9109-alt.github.io/pickle-house/>
- 정적 페이지 한 장: `index.html` + `assets/style.css` + `assets/app.js` (프레임워크·빌드 없음)
- 외부 요청 없음 (폰트·아이콘·이미지 모두 로컬/시스템)

## 기능

- **방 카드 → 상세 시트**: 마감일이 있는 항목은 오늘 날짜 기준으로 `D-n` / `오늘 마감` / `마감 지남`으로 계산됩니다.
- **피클 이동**: 방을 누르면 파란 피클이 FLIP 애니메이션으로 그 방으로 뛰어가고, 말풍선이 그 방의 상태를 알려 줍니다.
- **수뚜 님 피클 자리**: 거실 한켠의 분홍 피클을 누르면 인사말이 바뀝니다.
- **할 일 메모장**: 브라우저 `localStorage`에만 저장 (추가·체크·삭제, 완료한 일 지우기).
- **낮/밤 램프**: 크림 톤 낮과 따뜻한 밤을 오가며, 선택은 `localStorage`에 남습니다.
- 모바일(iPhone)과 PC 모두 대응. `prefers-reduced-motion` 존중, 키보드 포커스·Esc 닫기 지원.
